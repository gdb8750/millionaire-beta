# 100만장자되보기 🧪 베타 체험판

**⬇ 다운로드: [Millionaire-beta-windows.zip](Millionaire-beta-windows.zip)** (Windows · 약 7MB)  
파일 페이지 오른쪽 위의 다운로드 버튼(Download raw file)을 누르면 받아져요.

토스증권 계좌를 매일 아침 7시에 **개인 애널리스트처럼 정리해 주는 PC 프로그램**, 100만장자되보기의 체험판이에요.
가상의 **'엽 컴퍼니 체험 계좌'**로 화면·메일·보고서를 모두 미리 볼 수 있어요.

## 실행하기 (Windows)

1. `Millionaire-beta-windows.zip` 압축을 풀어요.
2. `100만장자되보기-베타.exe`를 더블클릭하면 브라우저에 체험판 화면이 열려요.
   - Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요 (코드 서명을 하지 않은 개인 프로그램이라 나오는 창이에요).
3. 다 봤으면 화면 맨 아래 **프로그램 종료**를 누르거나 창을 닫으면 끝이에요.

## 안전한가요?

- 토스증권·Gmail·Claude에 **연결하지 않아요**. 키·계좌번호·메일 주소를 묻지도, 저장하지도 않아요.
- 자동 실행이나 예약 작업을 **만들지 않아요**. 인터넷에도 접속하지 않아요 (링크를 직접 누를 때만 브라우저가 열려요).
- 화면의 잔고·종목·매매·시세 흐름은 **모두 지어낸 예시**예요. 뉴스·커뮤니티 칸은 '체험판 예시' 문장이고, 누르면 실제 검색 결과(Google 뉴스·Stocktwits)로 가요.
- 체험판 자료는 `%LOCALAPPDATA%\MillionaireDemo` 폴더에만 두고, 실행할 때마다 새로 만들어요. 지워도 돼요.

## 다른 증권 앱과 무엇이 다른가요?

- **내 계좌 기준으로** 시장을 해석해요 — "코스피가 내렸다"가 아니라 "그래서 내 계좌는 왜 줄었나".
- **습관을 고쳐 줘요** — 규칙을 어긴 매매, 이유별 30일 성적("남의 추천으로 산 건 평균 −6.8%")을 숫자로 보여줘요.
- **연말 세금까지** 챙겨요 — 해외주식 250만 원 공제, 손실 정리, 마감일을 미리 알려줘요.
- **위험할 때 먼저 알려줘요** — 계좌가 하루에 −5%·−8% 빠지면 🚨 비상 메일과 핸드폰 위젯 경보.
- **내 PC에서만** 돌아가요 — 키는 Windows 계정 암호화(DPAPI)로 이 PC에만 저장, 서버가 없어요.

- 토스증권 **Open API(읽기 전용)** 키와 Gmail 앱 비밀번호만 연결해요. **주문 기능은 아예 없어요.**
